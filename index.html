操作说明

一、开通并复制订阅

在官网选定套餐完成开通，登录用户中心复制 Clash 或通用订阅地址。订阅属于账号凭证，请勿公开分享。

二、安装官方客户端

对照「客户端选择」到 GitHub 发行页或应用商店安装对应程序。Windows 需允许防火墙通过；移动端注意系统 VPN 授权提示。

三、导入配置

打开订阅管理，粘贴 URL 并命名为 Tblack，执行更新。节点列表出现即表示导入成功。

四、连接与选择节点

开启系统代理或 TUN。优先测香港、日本、新加坡等近端节点。需要流媒体时，改选标注解锁或原生的入口。

五、日常维护

建议定期更新订阅以同步新节点。网络环境变化导致异常时，先换节点再重启客户端。旗舰用户可通过优先工单反馈线路问题。

节点与线路说明

常见问题 FAQ

Tblack机场如何下载并选择客户端？

按系统选择 Clash 内核或 Stash、Shadowrocket 等官方客户端，安装来源必须是作者发布页或应用商店。本官网说明导入方法，不托管安装文件，避免被二次打包。

机场订阅链接在哪里获取、如何导入？

套餐生效后进入用户中心复制订阅 URL，在客户端「订阅」或「配置」中粘贴并更新。若更新失败，检查链接完整性、系统时间以及是否被本地安全软件拦截。

基础版、旗舰版和团队版主要差别是什么？

差别在月流量、同时在线设备数、流媒体解锁范围、是否含 IPLC 游戏优化以及支持响应级别。基础版适合轻度浏览；旗舰版是个人主力；团队版面向多设备与定制路由。

Tblack机场适合哪些合法使用场景？

远程办公、文献与开源资源访问、个人流媒体、游戏加速以及差旅备用网络。请遵守所在地与目标站点的法律法规，不要用于未授权访问或侵权分发。

连接不稳定或速度不理想时怎么排查？

先更新订阅，换不同地区或协议节点；关闭其他代理软件；核对系统时间。公司网络或校园网有时需切换网络再试。旗舰用户可走优先工单说明时段与节点名称。

如何确认官方身份？客户端下载是否安全？

请核对 Tblack机场(Tblack) 品牌与本官网信息。客户端始终从软件官方渠道获取，只用本站提供的订阅地址。不要相信声称「免订阅」或「破解加速器」的第三方站点。
